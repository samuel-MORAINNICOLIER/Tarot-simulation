## Description
<p>
  Le projet vise la conception d'une application de simulation de divination par le tarot. </BR>
  Étant donné que le projet a déjà été réalisé par le passé et sans versionnage git, donc peu de commit seront présent. </BR>
  </BR>
  Le .exe du projet a été généré avec pyinstaller.
  L'installateur du projet à été généré avec Inno Setup Script Wizard dont les fichier de script .specs et .iss sont disponibles dans /setup.
</p>

## Installation du projet
   > Avoir Python et Pygame d'installé sur son pc ou son environnement </BR>
   > Python : https://www.python.org/downloads/ </BR>
   > Pygame : https://pypi.org/project/pygame/ </BR>
   > \> git clone https://github.com/samuel-MORAINNICOLIER/Tarot-simulation.git </BR>
   > \> cd TarotSimulateur </BR>

## Lancer le projet
   Lancer le fichier tarot.py ou utiliser l'installateur .exe :
   https://github.com/samuel-MORAINNICOLIER/Tarot-simulation/releases
